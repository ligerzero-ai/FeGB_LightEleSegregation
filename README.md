# FeGB Light Element Segregation — Figures and Analysis

Reproducible figure generation, analysis code, cached pipeline checkpoints, and raw DFT DataFrames accompanying the manuscript:

> **Grain boundary segregation of light elements and their effects on cohesion in ferritic steels**
>
> Han Lin Mai, Xiang-Yuan Cui, Tilmann Hickel, Simon P. Ringer, Jörg Neugebauer

## Quick start

```bash
# Reproduce all figures (one Jupyter notebook with markdown sections)
jupyter notebook reproduce_figures.ipynb

# Or regenerate one figure group at a time from the command line:
python scripts/MainFigures/generate_main_figures.py
python scripts/SupplementaryFigures/generate_SI_kpoint_parity.py
python scripts/SupplementaryFigures/generate_SI_kpoint_zoom.py
python scripts/SupplementaryFigures/generate_SI_nn_correlation.py
python scripts/SupplementaryFigures/generate_SI_vacancy_tables.py
```

All scripts use paths relative to the repository root, so they run from any working directory.

## Raw DFT data and analysis checkpoints

Both the **cached analysis checkpoints** (`data/checkpoints/`) and the **full raw DFT DataFrames** (`data/raw_data/`) are included in this repository. The figure-generation scripts read from `data/checkpoints/` directly. The raw DataFrames in `data/raw_data/` contain the full per-row VASP outputs (energies, forces, stresses, magnetic moments, ionic-step structures, job names, convergence flags) for every job that contributes to the figures and are sufficient to re-run the entire analysis pipeline from scratch. See `data/raw_data/README.md` for per-file descriptions and the column glossary.

## Grain boundary systems

Six CSL-type grain boundaries in bcc Fe are studied:

| GB | Sigma | N_atoms | k-points (static) |
|----|-------|---------|-------------------|
| S3-RA110-S1-11 | 3 | 72 | 6×3×1 |
| S3-RA110-S1-12 | 3 | 48 | 6×6×1 |
| S5-RA001-S210 | 5 | 76 (doubled) | 4×4×1 |
| S5-RA001-S310 | 5 | 80 (doubled) | 4×3×1 |
| S9-RA110-S2-21 | 9 | 68 | 4×6×1 |
| S11-RA110-S3-32 | 11 | 42 | 6×6×1 |

**Note:** Sigma 5 GBs use doubled cells for all solute calculations.

## DFT calculation parameters

- **Code:** VASP (PAW-PBE)
- **Energy cutoff:** 400 eV
- **Smearing:** Methfessel-Paxton order 1, σ = 0.2 eV
- **Fe pseudopotential:** PAW_PBE Fe 06Sep2000 (8 valence electrons)
- **Relaxation k-points:** KSPACING = 0.5 Å⁻¹
- **Static k-points:** Γ-centred meshes (see table above)
- **Electronic convergence:** 1×10⁻⁵ eV
- **Force convergence:** 0.01 eV/Å

## Segregation energy formula

```
E_seg(X) = E_GB[Fe,X] - E_GB[Fe] - (E_Bulk[Fe,X] - E_Bulk[Fe]) - n × μ_Fe
```

where:
- `E_GB[Fe,X]`: total energy of GB supercell with solute X
- `E_GB[Fe]`: total energy of pure Fe GB supercell
- `E_Bulk[Fe,X]`: total energy of 128-atom bulk supercell with solute X at its preferred site
- `E_Bulk[Fe]`: total energy of pure Fe 128-atom bulk (−1054.3935 eV)
- `μ_Fe = E_Bulk[Fe] / 128 = −8.2374 eV/atom`
- `n`: net change in Fe atom count between GB and bulk reference cells

### Computing E_seg from the raw pickles

A complete, self-contained example is provided at [`scripts/example_compute_eseg.py`](scripts/example_compute_eseg.py). Run it with `--verify` to cross-check the per-row output against the production `Eseg_KS` column in `data/checkpoints/08_df_compare_pairwise.pkl.gz` — every one of the 4,129 matched interstitial rows reproduces to machine precision (`max |ΔE_seg| = 0.000000 eV`).

Minimal version:

```python
import pandas as pd

# 1) Load the raw VASP DataFrames
df_gb   = pd.read_pickle("data/raw_data/FeGB_Int_vasp_database.pkl.gz")
df_pure = pd.read_pickle("data/raw_data/Fe_Pure_GB_SLAB_vasp_database.pkl.gz")
df_bulk = pd.read_pickle("data/raw_data/FeBulk_Int_vasp_database.pkl.gz")

# 2) Extract the final-step total energy from each row
def E_final(row):
    e = row["energy"]
    return float(e[-1]) if hasattr(e, "__len__") else float(e)
for df in (df_gb, df_pure, df_bulk):
    df["E"] = df.apply(E_final, axis=1)

# 3) Bulk Fe chemical potential reference
MU_FE = -1054.3935 / 128   # eV/atom

# 4) Per-row segregation energy: E_GB[Fe,X] - E_GB[Fe] - (E_bulk[Fe,X] - E_bulk[Fe]) - n*mu_Fe
#    For interstitials the Fe count is unchanged between GB and bulk reference, so n = 0.
def eseg_for_row(row, pure_E, bulk_E):
    return (row["E"] - pure_E[row["GB"]]) - bulk_E[row["element"]]

# Build lookup tables (parse GB and element from job_name; see example script for full parsing)
pure_E = df_pure.assign(GB=lambda d: d["job_name"].str.replace("-GB", "")).set_index("GB")["E"]
bulk_E = df_bulk.assign(element=lambda d: d["job_name"].str.extract(r"_([A-Z][a-z]?)(?:_|$)")[0]) \
                .groupby("element")["E"].min()

df_gb["GB"]      = df_gb["job_name"].str.extract(r"^([A-Za-z0-9-]+)-i[A-Z]")
df_gb["element"] = df_gb["job_name"].str.extract(r"-i([A-Z][a-z]?)-")
df_gb["Eseg"]    = df_gb.apply(lambda r: eseg_for_row(r, pure_E, bulk_E), axis=1)

print(df_gb.groupby(["GB", "element"])["Eseg"].min().unstack().round(2))
```

For the substitutional case, `n = -1` (the solute replaces one Fe atom), and `df_bulk` should be `FeBulk_Sub_vasp_database.pkl.gz`. The library helper `scripts/segregation.py:add_eseg_columns` handles both cases vectorised, including a host-per-atom correction when the GB and bulk supercells contain different numbers of Fe atoms.

Negative E_seg indicates energetically favourable segregation to the GB.
