# Supplementary Information Figure Scripts

Scripts to regenerate all figures appearing in the Supplementary Information.

## Scripts

| Script | SI Figures Generated | Dependencies |
|---|---|---|
| `generate_SI_kpoint_parity.py` | `SI_KP_vs_KS_Eseg_scatter.png`, `SI_KP_vs_KS_dEseg_histogram.png`, `SI_KP_vs_KS_dEseg_boxplot.png` | `08_df_compare_pairwise.pkl.gz`, `08_df_sub_compare_pairwise.pkl.gz` |
| `generate_SI_kpoint_zoom.py` | `SI_KP_vs_KS_dEseg_histogram_filt_pm02.png`, `SI_KP_vs_KS_dEseg_boxplot_filt_pm02.png` | Same checkpoints |
| `generate_SI_nn_correlation.py` | `SI_rho_vs_kNN_shell.png` | Hardcoded Spearman ρ values |
| `generate_SI_vacancy_tables.py` | `SI_vacancy_formation_by_GB.png`, `SI_vacancy_summary.tex`, `SI_vacancy_persite.tex` | PostgreSQL DB `FeGB_Seg_MPSmear_KP` on cmti002:5433 |

## Figures produced by the main analysis pipeline

The 8-panel starting-Voronoi-volume figures (`SI_StartVol_vs_Eseg_{H,He,B,C,N,O,P,S}.png`) and the relaxation-energy histogram (`SI_relaxation_energy_histogram.png`) are generated by the main analysis pipeline at `/u/hmai/2025_06_18_FeInterstitials/2026_04_01_KP_vs_KS_Analysis/generate_KP_figures.py` and are not duplicated here to avoid code divergence.

## Usage

All scripts use the pymatgen conda environment:
```bash
/cmmc/ptmp/hmai/mambaforge/envs/pymatgen/bin/python <script_name>.py
```

Outputs are written directly to `manuscript/Figures/` and `manuscript/` (for .tex tables).
