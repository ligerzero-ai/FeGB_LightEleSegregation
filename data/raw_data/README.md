# Raw DFT DataFrames

VASP-derived pandas DataFrames containing per-calculation outputs (energies, forces, stresses, magnetic moments, ionic-step structures, job names, etc.) for every job that contributes to the figures in the manuscript.

## Files

All files are gzip-compressed pandas pickles (`.pkl.gz`).

| File | Contents |
|---|---|
| `FeGB_Int_vasp_database.pkl.gz` | Interstitial GB segregation calculations |
| `FeGB_Sub_vasp_database.pkl.gz` | Substitutional GB segregation calculations |
| `Fe_Pure_GB_SLAB_vasp_database.pkl.gz` | Pure Fe GB and slab references |
| `FeBulk_Int_vasp_database.pkl.gz` | Bulk interstitial reference cells |
| `FeBulk_Sub_vasp_database.pkl.gz` | Bulk substitutional reference cells |
| `FeGB_Int_Cleaved_vasp_database.pkl.gz` | Cleaved interstitial GBs for Wsep (combined from three submission batches; 7,415 jobs after deduplication, 21 unconverged retained) |
| `FeGB_Pure_Cleaved_vasp_database.pkl.gz` | Cleaved pure GB references for Wsep |
| `chargemol_FeGBInterstitial.pkl.gz` | DDEC6 bond orders for segregated GBs |
| `chargemol_FeGBPure.pkl.gz` | DDEC6 bond orders for pure GBs |

## Per-row columns

Each DataFrame row corresponds to one DFT calculation. Common columns:

- `job_name` — unique identifier for the calculation
- `energy` — total DFT energy (eV) per ionic step (list/array; final entry is the converged value)
- `forces` — per-atom forces (eV/Å) per ionic step
- `stresses` — stress tensor per ionic step
- `magmoms` — per-atom magnetic moments per ionic step
- `structures` — pymatgen `Structure` (or JSON-serialised) per ionic step
- `convergence` — boolean SCF/ionic convergence flag
- `scf_steps` — number of electronic SCF iterations per ionic step
- Additional columns specific to each dataset (e.g., `calculation_description`, `GB`, `element`, etc.)
